Четыре варианта общего блока агентов

Макет для согласования. У общего тёмно-серого блока — одна пустая строка сверху и снизу, два символа свободного места слева и справа. Блоки здесь информационные: клик по ним не переключает Codex. Для выбранного потока предусмотрена подсветка, когда его ID доступен панели. Горизонтальная прокрутка сохраняет настоящий размер символов, если окно браузера уже выбранной ширины.

Вертикальные отступы добавляют две строки высоты. В текущей status-панели tmux доступно пять строк: для применения такого оформления потребуется компактнее разместить служебную информацию либо выделить панели отдельную область. Здесь показан желаемый дизайн без скрытого сжатия.
