# MCP, хуки, слушатель и контекст

## Разделение настроек

Глобальная обвязка и её исходники — этот репозиторий. Правила конкретного проекта остаются в его `.codex/config.toml`, `.codex/hooks.json` и адаптере. В Empirika это `.codex/hook.mjs`, делегирующий проверкам `.claude/hooks`. Здесь нет копии гвардов проекта: их изменения должны оставаться в одном месте.

Глобальный хук строки читает `session_id` и `cwd` события Codex. Он действует только при наличии `CODEX_TOOLS_RUN`, который устанавливает `codex-tools run`; обычные запуски не создают состояние строки. Хук не ставит задачи, не запускает слушателя и не передаёт текст в контекст модели.

Официально: [хуки и доверие](https://learn.chatgpt.com/docs/hooks), [настройки](https://learn.chatgpt.com/docs/config-file/config-reference), [команды строки состояния](https://learn.chatgpt.com/docs/developer-commands?surface=cli).

## Empirika

Проектный MCP подключается через `devops/empirika-codex-mcp.sh`. Без `EMPIRIKA_BASE_URL` выбран бой; токен получает проектный помощник, секреты не записываются в настройки. Список инструментов и определения хуков проверить в `/mcp` и `/hooks` новой сессии. Ленивая выдача схем инструментов сокращает объём определений в контексте, но не делает ответы вызванных инструментов бесплатными.

Слушатель поднимает агент через `exec_command` и читает через `write_stdin`:

```sh
CLAUDE_CODE_SESSION_ID=SESSION_ID bash devops/listen-events.sh
```

Опциональны `EMPIRIKA_EVENT_PROJECT` и `EMPIRIKA_EVENT_ASSET`. Перезапуск сервера Codex обрывает процесс монитора: после него слушатель нужно восстановить. Строка сообщает наблюдаемое состояние, а не заменяет протокол запуска.

## Контекст

Настройки верхнего уровня, до таблиц TOML:

```toml
model_context_window = 872000
model_auto_compact_token_limit = 800000
```

Это пример для проверенного каталога `gpt-6.1-sol` от 14.10.2026, а не универсальная настройка всех моделей. Каталог CLI 0.162.1 содержал default 500000, max 872000 и effective 95%; отсюда показанные 475000. С такой же долей 872000 даёт эффективные 828400. Настройка клиента не расширяет серверный предел модели. Установщик не меняет окно.

Штатная строка настраивается через `/statusline` и `tui.status_line`. В CLI 0.162.1 доступны, в частности, `model-with-reasoning`, `context-remaining`, `context-used`, `context-window-size`, `five-hour-limit`, `weekly-limit`, `git-branch`. Пользовательский command-backed сегмент штатной строки не документирован; эта обвязка выводит свою строку средствами tmux.
